A minimalistic 3D renderer using plain JS and WebGL. Includes texture mapping, directional and point lighting, shadowmapping, GPU particles, as well as 2 demo scenes. This was created as a part of my university thesis.

Demoscene 2 (winter scene) includes a 3D model created by EdwiixGG on Sketchfab (https://skfb.ly/6R6MM), used under the CC BY 4.0 license.
